빠르게 실행하기
두 가지 방법으로 실행할 수 있습니다.
A

스탠드얼론 데모 (설치 없이 바로 확인)

PowerShell에서 serve_localhost.ps1을 실행하면 http://localhost:8787이 자동으로 열립니다.

./serve_localhost.ps1
B

전체 MVP (실제 DB + RAG 검색 + Claude 연동)

백엔드를 직접 실행합니다. ANTHROPIC_API_KEY를 설정하면 Claude가 실제 자연어 답변을 생성합니다.

cd pm_rag_mvp/mvp/backend pip install -r requirements.txt python3 server.py

알려진 제한사항
MVP 단계의 의도된 한계입니다. 자세한 내용은 README를 참고하세요.
  • 인증/권한 미구현 (단일 사용자 가정)
  • 데이터 소스 연동은 SQLite 레코드 수 표시 수준의 시뮬레이션

  • SQLite + 단일 프로세스 구조라 다수 동시 쓰기 환경에는 부적합
